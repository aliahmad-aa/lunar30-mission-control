# 🌙 LUNAR 30: Mission Control

**Built for the NASA Space Apps Challenge 2026.**

An interactive lunar survival simulator where players command a four-member astronaut crew at the fictional Artemis Outpost Shackleton.

Can you keep your crew alive across seven simulated mission days while managing limited resources and completing scientific objectives?

## 🚀 Features

- Manage oxygen, water, food, power, and radiation protection.
- Respond to mission emergencies and make critical decisions.
- Monitor astronaut health and crew conditions.
- Complete scientific objectives and unlock discoveries.
- Access space-weather information through NASA's DONKI API when available.
- Review mission performance through an after-action report.

## 🛠️ Built With

- HTML5, CSS3, and Vanilla JavaScript
- NASA DONKI API
- NASA scientific and engineering references

## 🔬 NASA Resources

- [NASA LCROSS Mission – Lunar Water Ice](https://www.nasa.gov/mission/lcross/)
- [NASA Moonquakes](https://science.nasa.gov/solar-system/the-moon/moonquakes/)
- [NASA DONKI – Space Weather Database](https://kauai.ccmc.gsfc.nasa.gov/DONKI/)
- [NASA BVAD – Life Support Engineering Reference](https://ntrs.nasa.gov/citations/20210024855)

Real NASA observations and engineering references inform the educational content. Gameplay scenarios, resource percentages, and mission outcomes are simplified or fictional. DONKI data is retrieved when available; otherwise, the game uses labelled simulated scenarios.

## 🎯 Purpose

LUNAR 30 introduces students and young learners to the challenges of human lunar exploration through resource management, scientific discovery, and mission decision-making.
